### Real-Time FX Console for Live Guitar, Bass, and Audio Performance

RFX is a real-time effects console designed to bring the flexibility of modern DAW-based audio processing into a dedicated live-performance hardware format.

The goal of RFX is simple: give musicians the power of studio-grade plugins, open tone modeling, flexible routing, and expressive macro control in a performance-ready interface built for the stage.

---

## What is RFX?

RFX is a live audio processing platform built around:

* Plugin-based guitar and audio effects
* Real-time signal routing
* Macro knob control
* Expression pedal morphing
* Open tone modeling with NAM support
* Touchscreen performance control
* Hardware integration for live use

Unlike traditional modelers that lock users into a fixed ecosystem, RFX is being designed as an open, expandable performance platform.

---

## Core Features

### Open Tone Modeling

Integrate limitless tone models directly into your signal chain.

* Load and perform with NAM tone models
* Capture and craft custom tone profiles
* Access community-created tones
* Build rigs around open and expandable modeling technology

---

### Plugin-Based Signal Chains

Use industry-standard plugins as part of a live rig.

RFX is designed to support amp sims, impulse responses, mixing tools, mastering tools, and creative DSP effects commonly used in studio production.

Example plugin categories:

* Amp simulators
* Cabinet IR loaders
* Compression
* EQ
* Delay
* Reverb
* Modulation
* Pitch effects
* Saturation
* Utility processors

---

### Flexible Signal Routing

Build customizable signal chains for advanced live performance.

RFX is being designed to support:

* Linear routing
* Parallel routing
* Hybrid routing
* Dual amp blending
* Multi-band processing
* Wet/dry signal structures
* Center/side routing concepts

The goal is to make complex routing feel simple, musical, and performance-ready.

---

### Dimensional Expression

Control multiple destinations from a single expression pedal.

RFX expression control is designed to transform signal chains across tone, space, and motion with deeply expressive live control.

Potential mapped destinations include:

* Plugin parameters
* Track volume
* Bus volume
* Wet/dry blends
* Stereo position
* FX send levels
* Gain staging
* Parallel chain balance

Example expression concepts:

* Dynamic Tone Morph
* Spatial Bloom
* Parameter Sweep
* Gain Exchange
* Ambient Rise
* 3D Motion Pan
* Texture Shift
* Duality Merge

---

### Macro Control

RFX includes assignable macro controls for live performance and fast sound design.

Macro controls are designed to map multiple parameters into simplified performance gestures, allowing complex changes to be controlled from a small set of knobs or hardware controls.

Example macro destinations:

* FX plugin parameters
* Amp gain
* Output level
* Delay feedback
* Reverb mix
* Modulation depth
* EQ movement
* Parallel blend controls

## Project Vision

RFX is built around the idea that live musicians should not have to choose between:

* The flexibility of a DAW
* The reliability of dedicated hardware
* The openness of community tools
* The immediacy of a performance interface

RFX aims to combine these into one live-focused platform.
